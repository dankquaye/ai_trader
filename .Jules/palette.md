## 2026-02-10 - Invisible Blockers & Accessibility
**Learning:** Invisible overlays (modals) lacking `pointer-events: none` can silently block all UI interactions, causing confusion and automated test failures. Utility classes for state (like `.opacity-0`) must be explicitly defined if not generated by the build system.
**Action:** Always verify that hidden/overlay elements have `pointer-events: none` or `display: none` to prevent interaction blocking, and ensure utility classes exist in the CSS source.
