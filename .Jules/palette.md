## 2024-03-28 - Empty State for Trade History Table
**Learning:** Tables displaying dynamic data (like trade history) require a clear empty state to avoid looking broken or confusing when no data is present. This is a common pattern that improves user understanding of the application state.
**Action:** When implementing tables or lists that start empty or can be cleared, always add a visually distinct empty state (e.g., spanning all columns, using an icon and descriptive text) to guide the user.
