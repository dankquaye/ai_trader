## 2024-05-23 - CSS Utility Dependencies & Modal Visibility
**Learning:** Playwright's `not_to_be_visible()` assertion may fail for elements hidden via `opacity: 0` if CSS transitions are involved or if `opacity` is set via utility classes that are missing from the build. Always verify computed CSS properties (`to_have_css("opacity", "0")`) for transition-based visibility toggles, and ensure utility classes (like `.opacity-0`, `.pointer-events-none`) are actually defined in the stylesheet if not using a full build pipeline.
**Action:** When working with Tailwind-like utility classes in a raw HTML/JS environment, double-check that the used utilities are generated or manually defined in `<style>` blocks. For automated tests of fade-out animations, prefer checking computed opacity.
