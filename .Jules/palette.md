## 2026-03-24 - [Trade Analysis Modal Accessibility Improvements]
**Learning:** In Tailwind-based modals where display toggling utilizes `opacity-0` and `pointer-events-none` rather than `display: none` or `.hidden`, standard `div` close wrappers fail screen reader indexing. Without explicit `aria-hidden` attribute toggling dynamically inside JavaScript `openModal`/`closeModal` functions, screen readers will mistakenly read out background modals that are visually hidden. Also, converting `<div class="modal-close">` directly to semantic `<button>`s with `type="button"` and focus-visible utilities significantly improves keyboard support without additional JavaScript or layout shifts.
**Action:** When implementing or refactoring modals, explicitly set `role="dialog"` and `aria-modal="true"`, ensuring `aria-hidden` state syncs with visibility states in JavaScript. Change icon wrappers inside modals to `<button type="button">` and apply `aria-label`s and focus ring indicators (`focus-visible:ring-2`) to guarantee standard accessibility.
